# Repository stage

Единственное операционное поле, которое читает [`agent-prompt.md`](./agent-prompt.md). Держит DeltaFuse переносимым: промпт остаётся общим, стадия живёт здесь.

```yaml
stage: spec-first
```

## Values

| Значение     | Смысл                                                       | Разрешено                                                                                 | Запрещено                                           |
|--------------|-------------------------------------------------------------|-------------------------------------------------------------------------------------------|-----------------------------------------------------|
| `bootstrap`  | пакет спецификации в `docs/spec/` ещё не собран и не принят | Init Requirements в `docs/init/`, черновики ADR (`status: proposed`), сборка пакета спеки | эпики в `docs/todo/`, продуктовый код               |
| `spec-first` | пакет спецификации принят человеком                         | полный конвейер из [`workflow.md`](./workflow.md)                                         | реализация чего-либо, отсутствующего в `docs/spec/` |

## Changing the value

Поле переключает только человек. Переход на `spec-first` требует приёмки пакета спецификации, ревью которого выполняется из единственной точки входа `docs/spec/README.md` (см. [`roles.md`](./roles.md), раздел «Human only»). Агент может предложить переключение, но никогда не выполняет его сам.

Если этого файла нет, агент выводит стадию по наличию `docs/spec/README.md`.
