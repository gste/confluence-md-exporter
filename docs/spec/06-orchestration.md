# Orchestration

Prefect 3.x flow, изоляция страниц, артефакты UI, критерии успеха запуска. Как именно изоляция выражена (task / subflow / перехват) — не нормируется; нормируется наблюдаемое поведение.

## Flow

Один flow на запуск выгрузки. Flow читает вход, резолвит URL, обрабатывает страницы с параллелизмом `EXPORT_CONCURRENCY`, пишет `manifest.json` и `run_report.json`, публикует артефакты.

Кэш Prefect не заменяет disk-skip ([04-fetch.md#disk-skip](./04-fetch.md#disk-skip)).

Запуск — локальный: прямой вызов flow, `prefect flow run` или эквивалентный CLI-вход ([01-configuration.md#cli](./01-configuration.md#cli)). Деплой в кластер в первую версию не входит.

## Page isolation

Весь батч не падает из‑за одной страницы. Каждая валидная страница обрабатывается независимо: исключение, 403, 404, битое тело или сбой медиа на одной странице не отменяют остальные.

После попытки по всем валидным id flow всегда пишет каталог и отчёт (кроме невозможного старта, когда страницы ещё не обрабатывались).

## Run success

- Невозможный старт — процесс не выгружает страницы, код выхода `2`.
- Среди страниц нет `failed` (все `ok` и/или `skipped`, либо валидных id не было) — код выхода `0`. Запуск, в котором все страницы `skipped` (повтор без изменений), успешен.
- Есть хотя бы одна `failed` — код выхода `1`. Flow при этом завершает обход остальных страниц и пишет отчёт; он не обрывается на первой ошибке.

Коды выхода — [01-configuration.md#exit-codes](./01-configuration.md#exit-codes).

## Prefect artifacts

- На каждую страницу со статусом `ok` — Markdown-артефакт с превью выгруженного Markdown (frontmatter допускается включить; длинное тело допускается усечь, но превью не пустое, если тело не пустое).
- На запуск — артефакт-сводка: как минимум `ok` / `failed` / `skipped` / `invalid_urls` / `force_refresh` и перечень ошибок по `page_id`.

Содержимое выгрузки в превью не маскируется. Токены и пароли в артефакты не попадают.

## Read-only

Ни один шаг flow не вызывает Confluence API, который создаёт, изменяет или удаляет контент. Только GET и скачивание вложений.
