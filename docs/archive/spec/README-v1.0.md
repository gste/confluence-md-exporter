## Pack contents

Пакет пока состоит из одного файла: [`SDD.md`](./SDD.md). Нарезка на модули `NN-*.md` с requirement ID запланирована и не выполнена — до её завершения задачи в `docs/todo/` ссылаются на номера разделов `SDD.md`.

| §1              | Контекст, цели, границы MVP (§1.4), **human-gated зоны (§1.6)**                                      |
| §2–§3           | Компонентная схема, data flow, атомарность записи                                                    |

## How to read

Implementer читает файл задачи из `docs/todo/<epic>/` и только те разделы, на которые задача ссылается. Целиком документ читают Planner и Auditor. Правила работы — `AGENTS.md` и `docs/process/**`.

## Review gates

Список продуктовых зон, изменение которых требует одобрения человека независимо от размера диффа, объявлен в [`SDD.md` §1.6](./SDD.md). Задача, затрагивающая такую зону, обязана сослаться на эту секцию в DoD.
